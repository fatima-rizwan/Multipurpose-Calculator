## 🌟 About The Project

Multipurpose Calculator is a web-based application designed to make everyday calculations easier and more convenient. It combines multiple calculation functionalities in a single application with a clean interface and smooth user experience.

## 🚀 Features

<div align="center">

| Feature | Description |
|:---|:---|
| 🔢 Multiple Calculations | Different calculation tools in one place |
| ⚡ Fast Performance | Quick and efficient calculations |
| 🎨 Modern UI | Clean and attractive interface |
| 📱 Responsive Layout | Designed for different screen sizes |
| 🖥️ Easy to Use | Simple and intuitive experience |

</div>

## 🛠️ Built With

- **HTML5** – For page structure
- **CSS3** – For styling and responsive design
- **JavaScript** – For calculation logic and interactivity


## 💻 Getting Started

Run this project locally:

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**

```bash
cd Multipurpose-Calculator
```

**3. Launch the application**

Open `index.html` in your preferred browser.
